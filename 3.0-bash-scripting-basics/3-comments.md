## What is a comment?
- Meaning: A comment is a piece of text written inside a script or program that is completely ignored by Bash during execution. It is created by placing a `#` symbol at the beginning of the text or code line.
- Role in execution: Bash treats everything from the `#` symbol to the end of the line as a human-readable note, skipping it entirely when running the script.

Example:
```bash
# Prints out "Hello World!" to the terminal
echo "Hello World!"
```



## Commenting out a program

- You can comment out a program by placing a `#` symbol at the beginning of the line

Example:
```bash
# echo "Hello World!"
```

Keep in mind bash does not have multi line comments
