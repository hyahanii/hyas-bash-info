# 6.1 Case Statements

The case statement is a cleaner alternative to writing multiple elif conditions when you need to match a single variable against several different patterns or values. It starts with case, ends with esac ("case" spelled backwards), and uses ;; to terminate each branch.

```bash
case "$VARIABLE" in
    pattern1)
        # Code to run if VARIABLE matches pattern1
        ;;
    pattern2 | pattern3)
        # Code to run if VARIABLE matches pattern2 OR pattern3
        ;;
    *)
        # Default code to run if no other patterns match
        ;;
esac
```

## key components

- case / in / esac: The structural keywords defining the block.
- |  : Acts as an "OR" operator, allowing you to match multiple patterns for a single branch.
- ;; : Required at the end of each code block to signal the stop of that branch.
- *) : acts as the else fallback if nothing else matches.

Complete Example:
```bash
#!/bin/bash

# A simple script to check a service command
COMMAND="start"

case "$COMMAND" in
    start)
        echo "Starting the service..."
        ;;
    stop | halt)
        echo "Stopping the service..."
        ;;
    restart)
        echo "Restarting the service..."
        ;;
    *)
        echo "Unknown command: $COMMAND. Use start, stop, or restart."
        ;;
esac
```
