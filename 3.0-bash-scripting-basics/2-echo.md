# 2 echo

## Printing Text with echo
- Meaning: A built-in Bash command used to print text, strings, or variable values to standard output (the terminal).
- Role in execution: Used in scripts and interactive shell sessions to display messages, prompt users, or output data for feedback, debugging, or logging.

- Example:
```bash
echo "Hello, World!"
# Output: Hello, World!
```

## Common echo flags (-n and -e)

- **-n**: suppress the trailing newline so the next output appears on the same line.
- **-e**: enable interpretation of backslash escape sequences (like \n for a newline or \t for a tab).
