# printf

- stands for formatted print

- unlike echo printf does not automatically add a new line at the end unless you explicitly tell it to with \n

## simple example use

```bash
printf "Hello, World!"
```
this prints out the text on the screen, leaving your cursor sitting right at the end of the exclamation point instead of bumping down to a new line

## format specifiers

instead of just dumping raw variables like *echo $score*, *printf* uses format slots (specifiers)
to control what kind of data is being printed

- *%s*: handles text/string
- *%d*: handles whole numbers (integers)

```bash
name="Viper"
score=1500
printf "User: %s | Score: %d\n" "$name" "$score"
```

- what it does
it inserts the *$name* string into the *%s* slot and the *$score* integer into the *%d* slot cleanly, then ends with a newline (\n)

## ANSI escape codes and cursor control (ui magic!)
- this is main point of *printf* in my opinion, by using the octal escape sequence *\033* (which stands for the Escape key), you can controll your cursors exact position on the screen.

example: 
```bash
printf "\033[2A\033[25C"
```
- *\033*: tells the terminal an escape command is starting
- *[2A*: moves the cursor (up) 2 lines
- *[25C*: moves the cursor right 25 columns
