## What operators are


### Operator
- Meaning: An operator is a symbol that tells Bash what operation to perform.
- Role in an expression: It acts on one or more operands. In `4 + 5`, `+` is the operator, and `4` and `5` are the operands.

- Math example: `4 + 5 = 9`

- Example:
```bash
echo "$((4 + 5))"
# Output: 9
```


### Operand
- Meaning: An operand is a value that an operator acts on.
- Role in an expression: In `4 + 5`, `4` and `5` are the operands that the `+` operator adds.

- Math example: `4 + 5 = 9` (`4` and `5` are the operands.)

- Example:
```bash
echo "$((4 + 5))"
# Output: 9
```


### Value
- Meaning: A value is data used in an expression or produced as its result.
- Role in an expression: In `4 + 5 = 9`, `4` and `5` are the input values, and `9` is the result value.

- Math example: `4 + 5 = 9` (`9` is the result value.)

- Example:
```bash
echo "$((4 + 5))"
# Output: 9
```


### Expression
- Meaning: An expression is a combination of values and operators that represents a calculation or condition.
- Role in an expression: Bash evaluates the expression to determine its result.

- Math example: `4 + 5` is an expression.

- Example:
```bash
echo "$((4 + 5))"
# Output: 9
```


### Result
- Meaning: A result is the value produced when an expression is evaluated.
- Role in an expression: It is the outcome of the calculation or condition represented by the expression.

- Math example: The result of `4 + 5` is `9`.

- Example:
```bash
echo "$((4 + 5))"
# Output: 9

```

## Arithmetic contexts

### Arithmetic evaluation
- Meaning: The process where Bash calculates the result of a math expression rather than treating it as plain text.
- Role in execution: Tells Bash to evaluate numbers and math operators inside special syntax like `$(( ... ))`, converting the calculation into a final value you can store or print.

- Example:
```bash
result=$(( 5 + 5 ))
echo "$result"
# Output: 10
```

### Integer arithmetic
- Meaning: Doing math in Bash with whole numbers only, since Bash doesn't support decimals natively.
- Role in execution: Allows your scripts to perform calculations like addition, subtraction, or multiplication inside arithmetic constructs like `$(( ... ))` or `(( ... ))`.

- Example:
```bash
echo "$(( 10 / 3 ))"
# Output: 3
```

## Comparison contexts

### Numeric comparisons
- Meaning: Checking how numbers relate to each other, such as testing if one number is greater than, less than, or equal to another.
- Role in execution: Used inside conditional tests so your script can make numerical decisions, evaluating to a success or failure exit status.

- Example:
```bash
num=10
if (( num > 5 )); then
  echo "Number is greater than 5."
fi
# Output: Number is greater than 5.
```

### String comparisons
- Meaning: Checking how text values relate to each other, such as testing if two strings match, differ, or are empty.
- Role in execution: Used inside conditional tests so your script can make decisions based on text content, returning a success or failure exit status.

- Example:
```bash
name="Alice"
if [[ "$name" == "Alice" ]]; then
  echo "Hello, Alice!"
fi
# Output: Hello, Alice!
```

## Exit status and control

### Exit status
- Meaning: An exit status is a numeric code returned by a completed command to indicate whether it succeeded or failed (`0` for success, non-zero for failure).
- Role in execution: Bash stores this code automatically in the special variable `$?`, allowing scripts to check the exact outcome of the most recently executed command.

Example:
```bash
true
echo "$?"
# Output: 0

false
echo "$?"
# Output: 1
```


### Exit status control
- Meaning: How you manually tell a script or function when to quit and what status code to report back using `exit`.
- Role in execution: Putting `exit 0` or `exit 1` inside your own code lets you stop execution early when something goes right or wrong, handing control back with a clear success or failure signal.

Example:
```bash
check_config() {
  if [[ ! -f "config.txt" ]]; then
    echo "Error: Missing config file!"
    exit 1
  fi
  echo "Config looks good."
  exit 0
}

check_config
echo "This line won't run if the config is missing because exit 1 stops the script."
```
